## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Sunilmaske12/Core-Java-Practice.git
   ```

2. Navigate to the `Main` directory:

   ```bash
   cd Core-Java-Practice/Main
   ```

3. Compile a Java file:

   ```bash
   javac FileName.java
   ```

4. Run the compiled program:

   ```bash
   java FileName
   ```

   Replace `FileName` with the actual Java class name containing the `main()` method.
